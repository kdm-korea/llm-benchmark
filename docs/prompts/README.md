# 시스템 프롬프트 관리

시스템 프롬프트는 소스 코드에 직접 넣지 않고 이 폴더의 Markdown 파일로 관리합니다. 현재 작성되거나 실행에 사용된 시스템 프롬프트는 없습니다.

## 관리 규칙

- 용도별 하위 폴더와 버전 파일을 사용합니다. 예: `query-generation/v001.md`.
- 프롬프트 파일에는 실제 시스템 메시지 본문만 작성하고, 목적·입출력 규칙·변경 이유는 용도별 README에 기록합니다.
- 실행 설정에서 파일 경로를 참조하고 실행 결과에는 파일 경로와 내용 해시를 기록하도록 구현합니다.
- 실험에 사용한 버전을 수정해야 하면 새 버전을 생성합니다.
- 원문이나 사용자 입력을 시스템 프롬프트에 직접 혼합하지 않습니다.

일반적인 임베딩 검색 평가에는 LLM 시스템 프롬프트가 필요하지 않습니다. 질의 생성·정답 후보 생성 등 LLM을 쓰는 단계가 추가되면 해당 용도의 프롬프트를 작성합니다. 임베딩 모델의 필수 접두어나 입력 템플릿은 모델 설정에서 관리합니다.

## 1차 벤치마크 적용

EVE 데이터셋의 기존 Queries와 Qrels를 사용하므로 1차 실험에서 시스템 프롬프트를 사용하거나 LLM으로 평가 데이터를 생성하지 않습니다. 향후 필요한 시스템 프롬프트는 이 폴더에서 별도 관리합니다.

## 추가 작업: 실행 환경과 벤치마크 파이프라인 구현

### 수행 범위

사용자의 진행 요청에 따라 데이터셋·모델·MTEB 공식 자료를 확인하고 코드 구현과 검증을 진행했습니다. 앞선 문서 작성 단계의 미완료 항목 중 데이터 준비, 환경 구성과 파이프라인 구현을 이번 작업에서 수행했습니다.

### 실제 변경

- Python 3.12 가상환경을 생성하고 uv를 설치했습니다. `pyproject.toml`과 `uv.lock`으로 실행 환경을 구성했습니다.
- 공식 API에서 EVE 데이터 리비전과 모델 3종의 리비전을 확인하고 YAML 설정에 고정했습니다.
- 데이터 다운로드·해시 기록, EVE 매핑, 정합성 검증, 제목/본문 입력 구성과 질의 ID 생성을 구현했습니다.
- 실제 원본에서 중복 질의 1건을 발견했습니다. 설정에 `merge_max`를 명시해 관련 문서 합집합·최대 등급을 보존하고 이전/유입 등급을 검증 보고서에 남겼습니다.
- SentenceTransformer 추론, 모델별 접두어와 길이 제한, 실제 Pooling 및 잘림 통계 기록을 구현했습니다.
- 벡터 캐시의 입력/모델/환경별 키와 파일 SHA-256 검증을 구현했습니다.
- 전체 Corpus cosine 정확 검색과 문서 ID 내림차순 동점 처리를 구현했습니다. 캐시의 읽기 전용 벡터를 수정하지 않도록 복사합니다.
- MTEB 2.26.11의 Custom Retrieval Task와 RetrievalEvaluator를 연결하고, 동일 순위의 Recall을 core 지표와 교차 검증했습니다.
- 실행별 원본 JSON·질의 JSON·CSV·manifest 및 실패 상태 저장을 구현했습니다.
- `download`, `prepare`, `probe`, `run` CLI와 모델·질의 수·장치·배치 크기 선택 옵션을 추가했습니다.
- 실행 방법, 모델별 근거, 실제 데이터 확인 기록과 결과 폴더 안내를 작성했습니다. 데이터·캐시·결과는 `.gitignore`로 제외했습니다.

### 실행 및 검증

- 공식 API/README와 실제 JSONL: Corpus 59,786행, Qrels 5,999행, 고유 질의 5,998개를 확인했습니다.
- `.venv/bin/uv sync --cache-dir cache/uv`: 의존성을 설치하고 잠금 파일을 생성했습니다. MTEB 2.26.11, SentenceTransformers 5.7.0, PyTorch 2.14.1을 사용합니다.
- `.venv/bin/embedding-benchmark download`: 고정 리비전 다운로드 및 source.json 해시 기록을 확인했습니다.
- `.venv/bin/embedding-benchmark prepare`: 전체 데이터 정합성 검증 및 정규화 파일 저장을 확인했습니다. 정답 없는 질의는 0개이며 질의별 양수 정답 수 평균은 약 7.1962입니다.
- 초기 MTEB 테스트는 기본 홈 캐시 쓰기 제한으로 실패했습니다. 프로젝트 내부 `cache/mteb`를 사용하도록 수정한 뒤 통과했습니다.
- `.venv/bin/python -m pytest -q`: 16개 테스트 통과. 지표, 동점, 검색 배치, 읽기 전용 벡터, 중복 질의, 누락 ID, 캐시 재사용/변조, 실제 MTEB, 결과 저장과 실패 상태를 검증했습니다.
- 실제 E5 모델로 질의 2개를 인코딩하여 `(2, 1024)` 벡터 생성을 확인했습니다. 자동 장치 선택 결과는 MPS였습니다.
- `.venv/bin/embedding-benchmark probe`: 세 모델 모두 실제 판례 2개·질의 2개에서 `(2, 1024)` 벡터 생성에 성공했습니다. 세 모델 모두 MPS / torch.float32로 실행했고, BGE-M3·KURE-v1은 CLS Pooling, E5는 mean Pooling을 확인했습니다.
- 보고서: `results/probes/20261019T182110+0900-20010040.json` (`status: complete`, `benchmark_score: false`). 소요 시간에는 모델 다운로드·로딩이 포함되므로 처리 속도 비교 수치로 사용하지 않습니다.
- `.venv/bin/uv lock --check --offline --cache-dir cache/uv`: 잠금 파일과 프로젝트 의존성 일치를 확인했습니다.
- `.venv/bin/python -m compileall -q src`: 소스 컴파일 확인을 통과했습니다.
- Markdown 14개와 로컬 링크 24개의 대상 존재, 제공 원본 사본의 바이트 일치를 확인했습니다.
- 모델·검색·MTEB 구현은 `BenchmarkBackend`로 CLI에서 구성해 application에 주입합니다. core는 외부 모델과 MTEB에 의존하지 않습니다.

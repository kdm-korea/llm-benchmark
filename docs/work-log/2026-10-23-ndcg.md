# 2026-10-23 Recall·이진 nDCG 문서 통합

- 프로젝트 README·결과 보고서·평가 설계·모델 선택·결과 저장 안내와 블로그 원고에 이진 nDCG를 추가했습니다.
- 회수율과 순위 품질의 차이, 양수 관련성을 모두 1로 변환하는 방식, 동일 K 비교와 K별 비단조성, graded nDCG 및 답변 정확도와의 구분을 명시했습니다.
- 초록 요약 그래프를 Recall@20과 이진 nDCG@10 비교로 교체하고, nDCG 곡선과 세 모델·여섯 K의 상세 표를 추가했습니다. 도표 제목과 캡션은 명사형을 유지했습니다.
- 그래프 생성과 검증 코드를 확장하고 수치·원본 파일·이미지 해시를 보존했습니다. 모델 추론과 검색은 다시 실행하지 않았으며 원본 결과 파일도 변경하지 않았습니다.

- 1차: 세 모델의 MTEB 질의별 nDCG 평균을 저장된 집계와 소수점 5자리 반올림 허용 범위에서 비교했습니다. Recall도 CSV 및 저장 점수와 대조했습니다.

- 생성 이미지의 실제 좌표·수치 라벨을 검증된 값과 대조하고, 한글·축·범례·라벨의 가독성을 직접 확인했습니다.

# 작업 기록

실제 수행한 작업을 날짜별 문서에 기록합니다. 날짜는 Asia/Seoul 기준을 사용하며 같은 날짜의 작업은 해당 문서에 순서대로 추가합니다.

각 기록에는 요청 및 결정 근거, 실제 변경, 실행한 검증과 결과, 미완료 사항을 포함합니다. 실행하지 않은 명령이나 실험을 완료로 기록하지 않습니다. 키, 토큰, 개인정보 등 민감한 원문은 기록하지 않습니다.

# 실험 목록

이 문서를 실험 등록부로 사용합니다. 각 실험의 개별 안내에서 목적·입력 데이터·실행 방법·평가 기준·결과와 한계를 확인합니다.

| 실험 | 분야 | 평가 대상 | 상태 | 상세 기준·결과 |
| --- | --- | --- | --- | --- |
| [한국어 판례 임베딩 검색 비교](embedding/README.md) | 한국어 법률 검색 | 문서 단위 임베딩 모델의 검색 품질 | 전체 평가 완료 | [평가 설계](embedding-recall.md) · [결과 보고서](results/2026-10-20-embedding-recall.md) |

등록된 실험은 준비 완료와 실제 성능 평가 완료를 구분해 기록합니다. 후속 작업 방향은 [프로젝트 README](../../README.md)에 정리합니다.

## 문서 관리 규칙

- 루트 README에는 프로젝트 목적·현재 만든 것·앞으로 만들 것을 기록합니다. 실험 목록과 상태는 이 등록부에서 관리합니다. 개별 실험의 결과 표·그래프·실행 옵션은 해당 실험 문서에서 관리합니다.
- 실험마다 `docs/benchmarks/<실험명>/README.md`를 진입점으로 만들고 이 목록에 등록합니다. [개별 실험 문서 양식](experiment-template.md)을 사용합니다.
- 진입점에는 목적·현재 상태·코드·설정·실행 방법·평가 기준·산출물·한계를 적습니다. 상세 문서는 복제하지 않고 링크로 연결합니다.
- 결과에는 실행일·입력 데이터 및 모델 리비전·실행 조건·평가 지표·해석 범위를 기록합니다. 실행하지 않은 점수는 기록하지 않습니다.
- 원본 실행 결과는 `results/`, 원본 데이터는 `data/`, 캐시는 `cache/`에서 로컬로 관리합니다. 공유할 보고서·검증 기준은 문서로 남깁니다.
- 코드 테스트는 `tests/<실험명>/`에서 관리합니다. 벤치마크 성능 실험과 코드의 정상 동작 검증을 구분합니다.

기존 평가 설계와 날짜별 결과 보고서의 경로는 유지합니다. 등록부와 실험별 진입점을 통해 찾아갑니다.

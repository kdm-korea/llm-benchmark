## 2. 왜 이 테스트를 진행했는가

법률 RAG의 검색 단계에서 관련 판례를 놓치면 생성 모델에 필요한 근거를 전달할 수 없습니다. 모델의 일반적인 평가 점수나 한국어 특화 여부만으로 선택하지 않고, 한국어 법률 데이터에서 관련 판례를 얼마나 회수하는지 측정해 선택 근거를 확보하는 것이 목적입니다.

한 질의에 관련 판례가 여러 개 있을 수 있습니다. 이 데이터는 질의당 관련 문서가 평균 약 **7.20개**이므로, 정답 하나만 찾는지보다 관련 문서 집합을 얼마나 찾아오는지를 보는 Recall@K를 첫 평가 지표로 사용했습니다.

첫 실험에서는 전체 벡터의 정확 검색을 사용했습니다. Elasticsearch, HNSW/ANN, Hybrid Search, Reranker를 넣기 전의 임베딩 검색 기준선을 만들고, 근사 검색이나 결합 방식의 영향을 이번 비교에서 분리하기 위해서입니다.

## 3. 무엇을 어떤 조건에서 비교했는가

| 항목 | 실제 실행 조건 |
| --- | --- |
| 데이터셋 | EVE-Bench-Legal-2.0 |
| 검색 Corpus | 판례 문서 59,786개 전체 |
| 평가 질의 | 5,998개, 세 모델 모두 동일 |
| 정답 | Qrels의 relevance > 0 문서 집합 |
| 평가 제외 | 세 모델 모두 0개 |
| 중복 질의 | 원본 Qrels 5,999행 중 동일 질의 1건을 `merge_max`로 병합 |
| 문서 입력 | 제목과 text를 줄바꿈으로 결합, 판례 1개당 벡터 1개 |
| 질의 입력 | 모델별 설정의 접두어 적용; E5는 `query: ` / 문서는 `passage: ` |
| 검색 | L2 정규화 벡터의 cosine, 전체 Corpus Exact Top 100 |
| 벡터 | 세 모델 모두 1,024차원, 저장 dtype float32 |
| 지표 | 질의별 Recall@K의 산술평균(Macro Average) |
| 장치·배치 | Apple MPS, torch.float32, 임베딩 batch size 4 |
| 검증 | 자체 계산과 MTEB 2.26.11 Recall 교차 검증 |

`Recall@K(q) = |TopK(q) ∩ Relevant(q)| / |Relevant(q)|`

아래 백분율은 해당 식을 질의마다 계산해 평균한 값입니다. 질의별 관련 문서 수를 합친 뒤 한 번에 나눈 Micro Recall과는 구분합니다.

### 결과를 읽을 때 주의할 점

KURE-v1의 R@1 **18.36%**는 첫 결과가 관련 판례일 확률이 18.36%라는 뜻이 아닙니다. 질의별 여러 정답 중 첫 결과 하나로 회수한 비율을 평균한 값입니다.

이를 구분하기 위해 기존 질의별 순위에서 보조 통계를 계산했습니다. 이 통계는 모델을 다시 실행한 결과가 아니며, 1차 모델 선택의 주 지표는 위 Recall입니다.

| 모델 | 첫 검색 결과가 관련 판례인 질의 비율(Hit@1) | Top 100에서도 관련 판례를 하나도 못 찾은 질의 |
| --- | ---: | ---: |
| KURE-v1 | 81.59% (4,894/5,998) | 8개 |
| BGE-M3 | 77.86% (4,670/5,998) | 14개 |
| Multilingual E5 Large | 74.17% (4,449/5,998) | 32개 |

또한 R@100 **92.17%**는 92.17%의 질의에서 모든 정답을 찾았다는 의미가 아닙니다. KURE-v1이 Top 100에서 관련 판례를 전부 회수한 질의는 **4,088/5,998개(68.16%)**입니다.

## 7. 선택 근거의 적용 범위

- 한국어 판례 중심 데이터셋 한 개와 실행 한 번의 결과입니다. 사내 질의, 다른 법률 문서 유형이나 다국어 검색에서도 같은 순위라고 일반화하지 않습니다.
- Qrels는 후보 풀 기반 판정이므로 전체 Corpus의 모든 관련 판례를 포괄한다고 보장하지 않습니다. 미판정 문서는 계산상 정답에 포함되지 않지만 반드시 비관련 문서인 것은 아닙니다.
- 중복 질의는 관련 문서 합집합·최대 등급으로 병합했습니다. 원본 카드의 단순 덮어쓰기 예제와 평가 질의/정답 구성이 다를 수 있으므로 외부 발표 수치와 직접 동일시하지 않습니다.
- KURE-v1의 평균 점수가 높다는 사실을 확인했으며, 반복 실행이나 통계적 유의성 검정은 이번 보고서에서 수행하지 않았습니다.
- 생성 답변의 사실성·인용 정확도, ANN/HNSW, Hybrid Search, Reranker, API 비용, 온라인 p95 지연시간은 측정하지 않았습니다.

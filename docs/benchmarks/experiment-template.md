# 개별 실험 문서 양식

새 실험의 `docs/benchmarks/<실험명>/README.md`에 다음 항목을 작성하고 [실험 목록](README.md)에 등록합니다.

## 목적과 현재 상태

무엇을 비교하거나 검증하는지, 어떤 판단에 사용할지 적습니다. 계획·데이터 준비·실행 중·평가 완료 상태를 구분합니다.

## 코드·설정·데이터

구현과 코드 테스트 폴더, 설정 파일, 데이터 출처·리비전·범위를 연결합니다. 접근 조건과 정답의 한계도 기록합니다.

## 실행 방법

필요한 의존성 설치부터 데이터 준비·실험 실행·코드 검증까지 프로젝트 루트 기준 명령을 적습니다. 소량 동작 확인과 전체 성능 평가를 구분합니다.

## 평가 기준과 산출물

평가 단위·정답 판정·지표·분할·통제 조건과 결과 저장 위치를 적습니다. 상세 설계와 보고서는 링크로 연결합니다.

## 결과와 해석 범위

실행한 경우에만 실행일·조건·실행 ID·결과 보고서를 연결합니다. 무엇을 확인했고 무엇은 아직 확인하지 않았는지 적습니다.
